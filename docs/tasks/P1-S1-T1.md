   `dev` = `wrangler dev`, `lint` = `biome check .`, `format` = `biome format --write .`, `typecheck` = `tsc --noEmit`, `test` = `vitest run`, `e2e` = `playwright test`, `e2e:server` = `pnpm db:reset:local && pnpm seed:local && wrangler dev --port 8787`, `db:migrate:local` = `wrangler d1 migrations apply DB --local`, `db:reset:local` = `rm -rf .wrangler/state/v3/d1 && pnpm db:migrate:local`, `seed:local` = `tsx scripts/seed.ts --env local`, `seed:staging` = `tsx scripts/seed.ts --env staging`, `cf-typegen` = `wrangler types`.

2. **wrangler.jsonc**: `name: "byd-manuals-dev"`, `main: "src/index.ts"`, a current `compatibility_date`, `compatibility_flags: ["nodejs_compat"]`, `assets: { directory: "./public", binding: "ASSETS" }`, `observability: { enabled: true }`, `workers_dev: true`, `preview_urls: false` (preview URLs would share the real database; see `architecture.md` §8).

## Acceptance criteria
- `pnpm install && pnpm lint && pnpm typecheck && pnpm test` pass on a clean clone.
- `pnpm dev` serves `GET /healthz` → `{"ok":true,"env":"development"}` with header `X-Robots-Tag: noindex, nofollow`.
- `wrangler.jsonc` defines local, `staging` and `production`, each with `DB`, `MANUALS` and all vars listed above.
- All six route modules exist and are mounted; unknown paths (including `/admin`) return 404.
- `etbToSantim` / `santimToEtbLabel` behave as described, with no floating-point arithmetic.
- `app.css` defines every token in `docs/design.md` as a CSS variable; the three font families load from `/fonts/` (no requests to other hosts).
- Local and staging pages show the yellow "Test site. Do not send real payments here." banner; production config has the real telebirr number and name.

## How to test manually
1. `cp .dev.vars.example .dev.vars && pnpm install && pnpm dev`
2. Open http://localhost:8787/healthz → `{"ok":true,"env":"development"}`.
3. Open http://localhost:8787/css/app.css → the stylesheet loads; the network tab shows fonts only from `/fonts/`.
4. Run `pnpm lint && pnpm typecheck && pnpm test` → all green.
