## Why this model / review tier
Sonnet: streaming uploads under platform limits need care, but the approach is decided.
Auto: admin-only behind reviewed auth; it doesn't touch payments.

## Context
The catalog edit page has `<section id="uploads">`. Uploads go to the **admin Worker**, which shares the `MANUALS` bucket with the public Worker. R2 binding `MANUALS`. PDFs are under 100 MB (free-plan request body limit is 100 MB). **Never buffer**: `env.MANUALS.put(key, c.req.raw.body, …)` streams when the request has a `Content-Length`. Risk #6 in `architecture.md`: if a ~95 MB upload fails on staging, report it in the PR; the fallback (presigned direct-to-R2 PUT) would become a new task.

## Do this
1. `PUT /admin/uploads/manual/:versionId` (raw body, `Content-Type: application/pdf`):
   - Require `Content-Length` (411 if missing), > 0 and ≤ 100 MB (413 otherwise).
   - Key: `manuals/<slug>-en-<Date.now()>.pdf`. `put` with `httpMetadata.contentType = application/pdf`.
   - Verify it's a PDF without buffering: `MANUALS.get(key, { range: { offset: 0, length: 5 } })` and check the bytes are `%PDF-`. If not → delete the object, 400.
   - Update `manual_versions.r2_key`, `file_size`, `updated_at`. Then delete the previous object (if any). Return JSON `{ok:true, size}`.
2. `PUT /admin/uploads/image/:modelId`: same pattern, `Content-Type` must be `image/jpeg|png|webp`, ≤ 5 MB, key `images/<slug>-<ts>.<ext>`, update `car_models.image_key`, delete the old image.
3. `public/js/admin-upload.js`: file inputs in `#uploads` → `XMLHttpRequest` PUT with `upload.onprogress` → progress bar + percentage; on success, reload the page. Show server errors.
4. `catalog-edit.tsx`: render the two upload controls with the current file name/size and a "Replace" label when a file exists.

## Acceptance criteria
- Uploading a PDF to Dolphin makes it buyable: the catalog shows the price instead of "Coming soon", and a claim + download returns the uploaded file (FR-24, FR-3).
- Replacing a PDF deletes the old R2 object; existing download links serve the new file.
- A non-PDF renamed `.pdf` → 400, and no R2 object or DB change remains.
- A missing `Content-Length` → 411; oversized → 413.
- An image upload shows on the public catalog card.
- No call to `arrayBuffer()`, `formData()`, `blob()` or `text()` on the upload body.
