## Why this model / review tier
Sonnet: a small state machine with timers and error copy; easy to get stuck in states if done carelessly.
Auto: client-side only; the server enforces every rule.

## Context
The checkout page (`src/views/checkout.tsx`) renders `#claim-form`, `#txn`, hidden `versionId`, `#turnstile-slot`, `#claim-status`, and loads `/js/claim.js` as a module. API (see `architecture.md` §5): `POST /api/claim` and `GET /api/claim/status?ticket=` return `ok | pending | error`. No build step; plain ES modules.

**Design:** every state must match `docs/design.md` → Claim states (and the error copy there, which replaces any wording below) and `docs/design/checkout-mobile.dc.html`. In the design canvas, Tweaks → **Claim state** shows each state.

## Do this
1. `public/js/claim-core.js` (pure, no DOM; importable by Vitest):
   - `normalizeTxn(s)` (same rules as the server); `isValidTxn(s)` (`/^[A-Z0-9]{10}$/`).
   - `messageFor(code, supportContact)`: friendly text for `INVALID_FORMAT`, `INVALID_VERSION`, `ALREADY_USED`, `AMOUNT_TOO_LOW`, `EXPIRED`, `NOT_FOUND`, `RATE_LIMITED`, `BOT_CHECK_FAILED`, `INVALID_TICKET`, and a network-error default. Each message includes the support contact where the buyer needs a human.
   - `createPoller({ fetchStatus, onResult, intervalMs = 5000, timeoutMs = 600000, now, setTimer, clearTimer })`: polls until `ok`/`error`, then stops. On timeout, calls `onResult({status:"error", code:"NOT_FOUND"})` and stops. Returns `stop()`.
2. `public/js/claim.js` (DOM):
   - On input, show the normalized value back in the field (uppercase, no spaces). Keep `#txn-hint` visible (it is not replaced by errors; errors go in `#claim-status`). Client-side `isValidTxn` check before sending. Do not require a leading D.
   - Submit → disable the button, show "Checking…". POST. Then:
     - `ok` → replace the form with a success panel: green "Payment confirmed", a big **Download PDF** button (`href=downloadUrl`), and a `.notice`: "Save the PDF to your phone now. This link works for 24 hours and up to 3 downloads. There are no accounts, so we can't show it again." (FR-21).
     - `pending` → "Waiting for telebirr confirmation… This usually takes under a minute. Keep this page open." plus an elapsed timer (mm:ss); start the poller (FR-15). Stop polling on `ok`/`error`, on timeout, and on `pagehide`.
     - `error` → `.error` message from `messageFor`; re-enable the form (except for `ALREADY_USED`, where we also suggest checking the number).
   - Read the support contact from `data-support` on `#claim-form` (add this attribute in `checkout.tsx`).
3. `checkout.tsx`: add `data-support` and a `<noscript>` line ("Please enable JavaScript to verify your payment, or contact <SUPPORT_CONTACT>.").
4. `app.css`: any state-specific styles not already provided by the P1-S1-T1 classes (waiting circle, txn · time pill). CSS-only spinner; respect `prefers-reduced-motion` (no spin, show a static icon).

## Acceptance criteria
- Valid paid number → success panel with a working download button and the save-now notice (FR-4 story 4, FR-21).
- Not-yet-received number → waiting state; when the SMS arrives, it switches to success within about 5 s without a reload (FR-15).
- Polling stops after success, after an error, and after 10 minutes (no requests continue in the network tab).
- Lowercase input with spaces is accepted; `"ABC"` shows the format message ("10 letters and numbers, starting with D, copied from the telebirr app") without calling the server; a valid number starting with another letter is still sent.
- Every error code shows its friendly message.

## Tests to write or update
- `test/claim-core.test.ts`: normalize/validate; `messageFor` covers every code; the poller stops on ok, error and timeout (with fake timers and an injected `now`).

## How to test manually
1. `pnpm db:reset:local && pnpm seed:local && pnpm dev`, then open http://localhost:8787/m/byd-sealion-2026 (mobile view).
2. Enter `waitme 0001` → it shows `WAITME0001` and "Waiting for telebirr confirmation…".
3. In a terminal, post an SMS for `WAITME0001` (curl from P1-S2-T3) → within ~5 s the page shows "Payment confirmed" + Download PDF.
4. Tap Download → PDF saves. Reload, enter `WAITME0001` again → "already been used".
5. Enter `ABC` → format message; the network tab shows no request.
