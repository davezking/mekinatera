## Why this model / review tier
Sonnet: a well-specified pure function with the regex given; it needs careful edge-case handling.
Opus review: every payment the system trusts comes through this code. A wrong amount, date or transaction number releases PDFs incorrectly.

## Context
Pure TypeScript, with no DB or HTTP. `etbToSantim` exists in `src/lib/money.ts`. telebirr dates are DD/MM/YYYY HH:mm:ss in Ethiopia time (UTC+3, no daylight saving). Real example (PRD appendix):
```
Dear [Owner]
You have received ETB 500.00 from [Payer Name](2519****2531) on 26/09/2026 09:57:24. Your transaction number is DIQ55JS1ED. Your current E-Money Account balance is ETB [hidden].
Thank you for using telebirr
Ethio telecom
```
Expected: txn `DIQ55JS1ED`, 50000 santim, name `[Payer Name]`, phone `2519****2531`, paidAt = `Date.UTC(2026, 8, 26, 6, 57, 24)`.

## Do this
1. `src/lib/sms/patterns.ts`: export `TELEBIRR_PATTERNS: SmsPattern[]`, where `SmsPattern = { id: string; kind: "payment" | "ignore"; regex: RegExp }`. Patterns are tried in order.
   - `t2t-received-v1` (payment):
     `/You have received ETB (?<amount>[\d,]+\.\d{2}) from (?<name>.+?)\s*\((?<phone>[\d*]+)\) on (?<date>\d{2}\/\d{2}\/\d{4} \d{2}:\d{2}:\d{2})\. Your transaction number is (?<txn>[A-Z0-9]{10})\./`
   - `bank-deposit-v1` (ignore): matches deposit messages that mention a bank (e.g. `/\bfrom [A-Za-z .&]*Bank\b/i` or `/\bby transaction number\b/i`).
   - `outgoing-v1` (ignore): `/\bYou have (transferred|sent|paid)\b/i`.
   - `airtime-v1` (ignore): `/\b(airtime|recharged|package)\b/i`.
   Add a comment saying new wordings are added here, and that ignore patterns must never match the payment wording (a test checks this).
2. `src/lib/sms/redact.ts`: `redactSms(body)`: **first** normalize whitespace (real SMS contain double spaces, e.g. `Account  balance`), then replace the balance amount (`/(balance is ETB )[\d,]+\.\d{2}/gi` → `$1[redacted]`) and any run of 10+ digits (`/\b\d{10,}\b/g` → `[redacted]`). FR-10.
3. `src/lib/sms/parser.ts`:
   ```ts
   export type ParseResult =
     | { kind: "payment"; patternId: string; transactionNumber: string; amountSantim: number;
         payerName: string; payerPhoneMasked: string; paidAt: number }
     | { kind: "ignored"; patternId: string }
     | { kind: "failed"; reason: string };
   export function normalizeSmsBody(body: string): string   // collapse \r\n, \n, tabs, repeated spaces → single space; trim
   export function parseEatDate(s: string): number           // "DD/MM/YYYY HH:mm:ss" EAT → UTC ms; throws on invalid (e.g. 31/02, 25:00:00)
   export function parseTelebirrSms(body: string, patterns = TELEBIRR_PATTERNS): ParseResult
   ```
   - Normalize, try patterns in order. The first payment match → validate amount > 0 and a valid date, otherwise `failed`. The first ignore match → `ignored`. No match → `failed` with reason `"no_pattern"`.
   - Amount via `etbToSantim` (string-based). Trim the payer name. Never extract the balance or the owner's account number.

## Acceptance criteria
- The PRD appendix SMS parses to exactly the expected values (FR-8), including the UTC conversion.
- The same SMS split over different line breaks, with double spaces or `\r\n`, parses identically.
- `ETB 1,500.00` → 150000 santim.
- A date after midnight EAT converts to the previous UTC day (`01/10/2026 01:30:00` → `2026-09-30T22:30:00Z`).
- A bank-deposit style message → `ignored` (FR-7); random text from 127 → `failed`.
- Lowercase or 9-character transaction numbers do not match the payment pattern.
- `redactSms` of the appendix SMS (with a real balance like `ETB 12,345.67`) no longer contains `12,345.67`.
- No ignore pattern matches the appendix payment SMS.
- The real **outgoing** telebirr SMS below → `ignored` with pattern `outgoing-v1`, and `redactSms` removes its balance despite the double spaces:
  ```
  Dear [Owner]
  You have transferred ETB 500.00 to [Recipient Name] (2519****3118) on 22/10/2026 10:21:55. Your transaction number is DJM95ZKH8J. The service fee is  ETB 1.74 and  15% VAT on the service fee is ETB 0.26. Your current E-Money Account  balance is ETB 1,679.92. To download your payment information please click this link: https://transactioninfo.ethiotelecom.et/receipt/DJM95ZKH8J.

  Thank you for using telebirr
  Ethio telecom
  ```
